# Лист

Курсовой проект по дисциплине «Серверная веб-разработка».

Филиппов Фёдор Геннадьевич, группа 253-321.

Сайт: https://filippov-253-321.alwaysdata.net/coursework/

Веб-приложение создаёт короткие художественные истории по замыслу пользователя. Можно выбрать жанр и объём: одну, две или три страницы. Истории сохраняются в личном аккаунте, редактируются и скачиваются в PDF. Опубликованные произведения доступны в библиотеке с комментариями.

## Запуск

Требования: PHP 8.1+, PDO SQLite, DOM, mbstring, OpenSSL и allow_url_fopen=On.

```sh
php -S localhost:8080 -t public router.php
```

Открыть http://localhost:8080.

База создаётся автоматически в storage. Папки storage и storage/cache должны быть доступны PHP для записи.

Для настоящей генерации задайте переменную окружения OPENROUTER_API_KEY либо скопируйте config/secrets.example.php в config/secrets.php и укажите ключ. Файл secrets.php исключён из Git. Используется только бесплатный маршрутизатор openrouter/free.

На Apache корневой папкой сайта должна быть public. Для маршрутизации нужны mod_rewrite и AllowOverride All.

На действующем Alwaysdata публичные файлы находятся в www/php-labs/coursework, остальные файлы — в www/coursework-private. В размещённом public/index.php APP_ROOT указывает на эту отдельную папку. Исходный вариант в репозитории использует обычную структуру проекта с public. Ключ и SQLite не доступны по HTTP и не входят в репозиторий.

## Структура

- public — входной файл, стили и JavaScript;
- src/Core — маршрутизатор, представления, авторизация и подключение к базе;
- src/Controllers — обработка запросов;
- src/Models — работа с записями;
- src/Services — запросы к ИИ и экспорт PDF;
- views — PHP-шаблоны страниц;
- database — схема SQLite;
- vendor/dompdf — библиотека PDF и её зависимости.

## Генерация

Каждый запрос создаёт одну страницу. План и готовые страницы сохраняются между запросами. После ошибки создание можно продолжить. Повторное скачивание PDF не обращается к ИИ.

Бесплатный API имеет внешние ограничения и может быть временно недоступен. Приложение дополнительно ограничивает число запросов: 45 в сутки на сайт и 15 на пользователя.

## Зависимости

Dompdf 3.1.6 включён в vendor/dompdf с оригинальными лицензиями. Он используется для формирования PDF с кириллицей. Исходные тексты приложения находятся в src, views и public.
